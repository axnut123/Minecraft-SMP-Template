# 定期公告系统 (Announcer)

## 功能说明

这是一个 Minecraft Bedrock Edition 服务器定期公告系统，可以在服务器公屏定期发送自定义公告。

### 主要特性

- ✅ 定期循环发送公告
- ✅ 支持自定义公告内容
- ✅ 支持自定义发送间隔
- ✅ 支持颜色代码和格式代码
- ✅ 可动态启用/禁用
- ✅ 支持动态重载配置

## 配置说明

编辑 `scripts/config.json` 文件：

```json
{
  "enabled": true,           // 是否启用公告系统 (true/false)
  "interval": 300,           // 发送间隔（秒）
  "announcements": [         // 公告内容数组
    "§6[公告] §f欢迎来到服务器！"
  ]
}
```

### 配置参数

| 参数 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `enabled` | 布尔值 | 启用/禁用公告系统 | `true` |
| `interval` | 数字 | 公告发送间隔（单位：秒） | `300` |
| `announcements` | 数组 | 公告内容列表 | `["欢迎"]` |

## 使用示例

### 基础公告

```json
{
  "enabled": true,
  "interval": 300,
  "announcements": [
    "§6[公告] §f欢迎来到服务器！",
    "§e服务器规则：禁止破坏他人建筑",
    "§a服务器1小时后进行备份"
  ]
}
```

### 进阶公告（包含格式）

```json
{
  "enabled": true,
  "interval": 600,
  "announcements": [
    "§l§6[系统公告]§r §f服务器正常运行中",
    "§n§b官方网站§r: §aexample.com",
    "§c§l重要§r: §f禁止滥用命令！"
  ]
}
```

## API 接口（给脚本开发者）

如果你需要在其他脚本中使用公告系统，可以导入以下函数：

```javascript
import {
  startAnnouncer,           // 启动公告系统
  stopAnnouncer,            // 停止公告系统
  sendCustomAnnouncement,   // 发送自定义公告
  reloadConfig,             // 重载配置
  ANNOUNCER_CONFIG          // 获取当前配置
} from "./scripts/Main.js"

// 发送自定义公告
sendCustomAnnouncement("§a[提醒] §f这是一条自定义公告")

// 动态更改配置
reloadConfig({
  enabled: true,
  interval: 120,
  announcements: ["新公告1", "新公告2"]
})
```

## 工作原理

1. **初始化**: 世界初始化时自动启动公告系统
2. **循环**: 使用 `system.runInterval` 定时器每秒检查一次
3. **发送**: 当达到设定间隔时，发送下一条公告
4. **轮转**: 循环显示公告列表中的所有内容

## 注意事项

- 最小间隔为 1 秒
- 公告内容不能为空
- 间隔时间设置过短可能影响服务器性能
- 建议间隔在 60-600 秒之间（1-10分钟）
- 修改配置后需要重新加载行为包才能生效

## 故障排查

| 问题 | 解决方案 |
|------|---------|
| 公告未显示 | 检查 `enabled` 是否为 `true` |
| 颜色显示错误 | 检查颜色代码格式是否正确 |
| 间隔过长/过短 | 修改 `interval` 参数 |
| 重复内容 | 检查 `announcements` 数组中是否有重复项 |
